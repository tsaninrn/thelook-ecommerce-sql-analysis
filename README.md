# TheLook E-commerce SQL Analysis

## 1. Project Overview

This project analyzes the TheLook e-commerce public dataset using SQL in Google BigQuery.

It simulates the role of a Junior Data Analyst working with an online fashion retailer to understand product performance, customer orders, sales performance, cancellations, and product returns.

The project starts with basic SQL (filtering, aggregation, JOINs) and expands step by step into more comprehensive business analysis.

> **Note:** TheLook is a **synthetic (simulated) dataset** provided by Google. Findings describe patterns in this dataset and are not real business results. Because Google refreshes the dataset periodically, exact figures may change over time. Query execution dates are recorded in the results.

## 2. Dataset Information

- **Dataset:** TheLook E-commerce
- **Source:** Google BigQuery Public Dataset
- **Project ID:** `bigquery-public-data`
- **Dataset ID:** `thelook_ecommerce`
- **SQL Dialect:** GoogleSQL (BigQuery Standard SQL)

### Tables Used

| Table | Description |
|---|---|
| `products` | Product information, categories, brands, and prices |
| `users` | Customer information and profiles |
| `orders` | Order-level information and order status |
| `order_items` | Individual items within orders, including sale price and item status |
